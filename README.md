# eco cvc

Site vitrine d'eco cvc — installation, entretien et dépannage de climatisations réversibles et pompes à chaleur air-air. Artisans certifiés RGE QualiPAC.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS + shadcn-ui
- Framer Motion
- React Router

## Démarrer en local

```sh
bun install
bun run dev
```

Le serveur tourne sur [http://localhost:8081](http://localhost:8081).

## Build production

```sh
bun run build
```

Le résultat est dans `dist/`, prêt à être déployé sur n'importe quel hébergeur statique.
